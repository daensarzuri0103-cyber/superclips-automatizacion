Política de Privacidad

Última actualización: 16 de septiembre de 2026

Esta Política de Privacidad explica cómo Superclips Automatización maneja la información necesaria para conectar y utilizar servicios externos autorizados por el usuario.

1. Información utilizada

Cuando un usuario conecta una cuenta de una plataforma externa, Superclips Automatización puede procesar la información necesaria para autenticar la cuenta y utilizar las funciones expresamente autorizadas por el usuario.

2. Uso de la información

La información se utiliza únicamente para proporcionar las funciones solicitadas por el usuario, como gestionar y publicar contenido de video mediante las APIs oficiales de las plataformas conectadas.

3. Autorización

Superclips Automatización solamente accede a una cuenta externa después de que el usuario haya autorizado el acceso mediante el sistema oficial de autenticación de la plataforma correspondiente.

4. Compartición de información

Superclips Automatización no vende información personal. La información solo podrá transmitirse a los servicios externos necesarios para realizar las acciones autorizadas por el usuario.

5. Seguridad

Se aplican medidas razonables para proteger las credenciales, tokens de autorización y demás información utilizada por el servicio.

6. Revocación del acceso

El usuario puede revocar el acceso concedido a una plataforma externa utilizando las opciones disponibles en dicha plataforma.

7. Cambios en esta política

Esta Política de Privacidad podrá actualizarse cuando sea necesario. La versión vigente estará disponible públicamente en esta página.
